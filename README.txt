MINECRAFT 1.21.11 (FABRIC + SODIUM) - STANDALONE DIRECT LAUNCHER
================================================================================

This package is completely standalone and does NOT require Lunar Client launcher
or any Electron launcher to run. It launches Minecraft 1.21.11 Fabric directly
using the embedded Java 21 runtime.

HOW TO PLAY:
1. Double-click "Launch-Minecraft-1.21.11.bat" to play!
2. (Optional) Run "Change-Username.bat" to set your custom in-game name.

FEATURES & OPTIMIZATIONS:
- Zero launcher overhead (saves ~500MB+ RAM by not running Chromium/Electron).
- Embedded Zulu OpenJDK 21 LTS runtime (no Java installation needed).
- Pre-configured 2048 MB memory allocation (safe for low-end / potato PCs).
- Sodium & FerriteCore pre-installed for maximum FPS and minimal RAM usage.
- Completely portable (can be placed anywhere on your PC or on a USB drive).

TROUBLESHOOTING:
- To see launch console logs for troubleshooting:
  Open Command Prompt in this folder and run:
    Launch-Minecraft-1.21.11.bat --debug
